Set up your token — one time

Needed only to save or delete entries (reading needs no token). Stored only in this browser and sent only to api.github.com.

  1. Have a GitHub account, and be a collaborator on this repo. New person: the owner adds you in repo Settings → Collaborators, and you accept the invite (check email / github.com notifications).
  2. Open the token page below (it pre-checks the right scope) and sign in.
  3. Set a Note and an expiration. Confirm repo → public_repo is checked.
  4. Click Generate token, copy it, paste below, and Save.
Create a classic token ↗

Use a classic token with the public_repo scope so it works for collaborators too. The archive is a public file.
